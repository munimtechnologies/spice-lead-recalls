# furan-2018 0.1.0: CFIA's open 2018-19 furan, 2-methylfuran and 3-methylfuran file against every figure CFIA printed for it — result

RESULT-MARKER: furan-2018-0.1.0-result

By MV2 of Munim, Inc. Prepared with AI agents working in his name. Text CC BY 4.0; code Apache-2.0.

This grades the pre-registration [furan-2018-0.1.0-prereg.md](furan-2018-0.1.0-prereg.md), which was
public first, at tag `v0.4.81`. The sealed job `furan-2018-v1` ran on 2026-10-30 at 08:24 UTC
(python:3.12, 1 GB, no host paths). It waited for the registration's marker to be public,
checked that its bundled `furan_2018.py` and `test_furan_2018.py` were byte-identical to the
published copies, ran the 13 offline tests and only then read the file (133,082 bytes; its MD5
matches the portal record; SHA-256 `f57d7d77…34601`). **The gate passed, and 2 of 9 graded
items held: the gate and P2.** Most of the misses are informative: they show where the report
and the open file part ways.

This is a reproducibility check of open government data, not a compliance finding and not about
any brand. Health Canada judged the levels in this survey not a health concern, and Canada has
no maximum levels for furan or the methylfurans. It is not dietary or medical advice.

## Headlines

1. **The per-sample totals reproduce.** Figure 1 lists the furans level (furan + 2-methylfuran +
   3-methylfuran) of every detected sample. The file gives 174 of those 175 values to the printed
   digit. Table 2's detected count, minimum, maximum and positives-only average hold for canned
   fish, canned meat, canned milk and soy sauce, and the text's overall range (1.23 to 179 ppb)
   holds.
2. **One dried beverage mix differs.** In the file, sample `C2018FRAN00170` (a hot powdered
   beverage mix declared domestic) has 3.0 ppb of furan and no methylfurans. Figure 1 has no 3.0.
   It lists 5.89 instead, and no sample in the file has that value. Table 2's beverage minimum
   (5.1) fits the figure, not the file. This is the sample whose furan row has an empty date and
   test type, which the structure preview had already flagged.
3. **There are 175 detected samples, not 176 (P1 failed; the competing reading registered with it
   holds).** No sub-1 ppb beverage value exists. The printed total of 176 and the 9.7 ppb beverage
   average are slips on the page: 9.7 is Figure 1's 15 beverage values (sum 155.18) divided by 16.
   The file's 15 beverage values average 10.15 ppb, and the figure's average 10.35.
4. **The grand average is 45.31 ppb, not the printed 45.5 (P2 held).**
5. **The report counts one more canned milk than the file has (C2 failed only on sample
   counts).** The file has 15 `Evaporated Milk`, 38 `Milk Powder`, 5 `Dairy Alternative` and 42
   powdered beverage mixes, as predicted. But none of the 5 dairy alternatives has furans, so P4's
   split ("exactly one detected") failed. The file's origins point to which sample the report
   moved. They match Table 1 exactly for canned fish, canned meat, beverage mixes and soy sauce.
   The only difference is one domestic sample: canned milk is 13 domestic / 0 imported / 2
   unspecified in the file against 14 / 0 / 2 printed, and dried dairy is 21 / 5 / 17 against
   20 / 5 / 17. No dairy alternative is declared domestic (3 imported, 2 unknown). So the simplest
   reading of the report's 16 and 42 is that it counts one domestic sample as canned milk that
   the file labels `Milk Powder`. That sample has no furans, so the detected count (10) does not
   change.
6. **The per-analyte figures do not reproduce (C3, CT, P3 failed).** The furans totals match, but
   the figures that depend on which analyte is which do not:
   - **Table 3 (furan only):** of the 15 printed minima, maxima and averages for the five product
     types with detections, the file's furan column matches one (soy sauce maximum, 159 against
     159.09). For canned milk, for example, the file's furan values run 13.83 to 31.02 ppb (average
     18.53), while the table prints 1.27 to 20.8 (6.87). Table 3 also counts 43 beverage mixes,
     but the file has 42.
   - **"12 samples contained all 3 furan analogues, 11 of which were canned meat":** the file has
     59 such samples, 33 canned fish and 26 canned meat. Fish lead at every 3-methylfuran
     cut-off, so no single limit of quantification turns the file into "11 of 12 canned meat".
   - **"In 52% of the samples, only 1 of the 3 furans was present"; furan and 2-methylfuran both
     in 38%:** the file has 15 single-analogue samples (6.0% of 250, 8.6% of the 175 detected) and
     160 with both (64.0% and 91.4%). Neither base fits.
   - **"In canned milk products, the average 2-methylfuran level was nearly twice that of
     furan":** in the file it is the other way round. The canned-milk furan values sum to 185.32 ppb
     and the 2-methylfuran values to 13.13, so furan is about 14 times higher. The overall order
     the page gives (furan highest, 3-methylfuran lowest) does hold: summed over all samples,
     furan 5,056.34, 2-methylfuran 2,699.08, 3-methylfuran 173.31 ppb.

   Totals that match while the per-analyte splits do not suggest that the published file and the
   report's per-analyte summaries come from differently arranged versions of the results. The file
   cannot say which is right.

## Gate (passed)

The gate required: the byte size from the portal record; the five key columns found by header;
750 rows; samples exactly `C2018FRAN00001` to `C2018FRAN00250`; only the three analyte labels;
unit `ng/g` and plan `2018_TS023` on every row; only the eight known product labels; and every
value a number of 0 or more. Every row is a plain number (394 above 0, 356 zeros); no `<` values,
tokens or blanks. Sample 172 has two 3-methylfuran rows (both 0) and no 2-methylfuran row, as the
preview showed. Its 2-methylfuran is left out of the sum, not set to 0.

## Limits

- "Detected" is the file's own coding (a value above 0). The file gives no limit of detection or
  quantification. The report may count an analogue as "present" by a different rule. The
  all-three check above covers single 3-methylfuran cut-offs only.
- The reading of the 16th canned milk rests on Table 1's origins, which are printed. Two errors
  that cancel could also explain the counts. The file cannot say which sample the report moved.
- The per-analyte disagreement is described, not explained. We found no simple rule (another
  analyte, pooled analytes, all-sample averages) that reproduces Table 3 from the file.

Prior art: on 2026-10-30, searches found CFIA's report page, the open dataset, the 2023-24
follow-up report, EFSA's 2017 opinion and reviews of furan occurrence. They found no analysis of
this file and no check of it against the printed tables. Nothing they found noted the 175/176
count, the divided-by-16 average, the 3.0/5.89 sample, the extra canned milk or the per-analyte
mismatches.

## Reproduce it

- `data/furan_2018_samples.csv` is the sealed job's output, one row per sample: product, report
  type, origin, function, date, raw rows, furan, 2-methylfuran, 3-methylfuran, furans and the
  number of analytes detected.
- `data/furan_2018_summary.json` is the sealed grader record: the gate, every check and
  prediction with observed values, the printed-figure arithmetic, census and provenance.
- `test_furan_2018_result.py` is a pinned test. It does not import the grader. With its own
  code and its own copy of the printed figures, it rebuilds from the CSV and checks against the
  sealed record:
  - the counts and Table 2 rows;
  - the Figure 1 matching and the 3.0/5.89 sample;
  - the 175/176 and 9.7 arithmetic and the grand average;
  - the Table 3 comparison, the analogue counts and shares, and the canned-milk ratio;
  - the Table 1 origin counts.

A sealed follow-up job (`furan-2018-result-v1`) fetches these published files from GitHub and
re-runs the pinned test on them. The grading code `furan_2018.py` and the pre-registration are at
tag `v0.4.81`.
