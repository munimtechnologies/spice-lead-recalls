# pah-2019 0.1.0: the value grader for CFIA's open 2019-20 PAH file (items D2-D5), fixed before any value is read

GRADER-MARKER: pah-2019-0.1.0-grader

Made with AI agents working in MV2's (Munim, Inc.) name. Text CC BY 4.0; code Apache-2.0.
Not a compliance finding, not about any product or brand, and not dietary or medical advice.

This note commits `pah_2019.py` and its offline tests `test_pah_2019.py` **before any result
value of CFIA's 2019-20 PAH file is read.** The predictions are D2-D5 of the pre-registration
[bpa-pah-report-0.1.0-prereg.md](bpa-pah-report-0.1.0-prereg.md) (tag `v0.4.86`). D1, the
names-only census, held; it and the label map are in the
[grader note](bpa-pah-report-0.1.0-grader.md) (`v0.4.90`). The sealed job `pah-2019-v1` waits
until all three notes are public, checks that its bundled code equals the published code, runs
the tests, and only then reads the file.

## The grader

- **Gate:** byte size 831,190 as on the portal record; the 15 bilingual columns found by their
  English headers; 4,736 rows = 296 samples x 16 PAHs, one row each; every sample ID of the form
  `C2019PAHS#####A`; unit ng/g and plan `2019_TS024` on every row; only the 27 product labels the
  census found; every result a number >= 0. If the gate fails, D2-D4 are reported as ungraded.
- **TEQ, as registered:** benzo[a]pyrene + 0.1 x benz[a]anthracene + 0.1 x benzo[b]fluoranthene
  + 0.01 x chrysene, in ppb (the file's ng/g, no conversion). A sample is detected when its TEQ is
  above 0. Averages are over detected samples. A printed figure matches when the file's figure is
  within half a unit of its last printed digit.
- **Label map:** exactly the table in the grader note (infant formula 34 = `Infant Formula -
  Dairy` 23 + `- Soy` 11; nuts, seeds and butters 114 from 24 labels; olive oil 148 =
  `Oil - Olive`).

| ID | Registered | Graded as |
|---|---|---|
| D2 | Table 2's infant formula (34, 16, 0.001, 0.776, 0.12), nuts (114, 44, 0.001, 2.93, 0.17) and total (296, 181, 0.001, 3.25, 0.21) rows | at least 11 of the 12 cells (detected, min, max, average) match, and 181 detected |
| D3 | olive oil: 121 detected, min 0.002, max 3.25 | those three cells; the average is reported against both Table 2's 0.24 and Table 3's 0.23, no prediction |
| D4 | 16 of 23 milk-based formulas detected, max 0.776; no soy formula detected; the nut maximum 2.93 is the pumpkin seed butter and the next nut is below 0.773; exactly 3 olive oils at 0.700 or more | all four checks; the pomace clause (four pomace oils, average 0.19, max 0.569) is **ungraded**, because no label separates pomace oil |
| D5 | descriptive | olive oils with benzo[a]pyrene above 2.0 ng/g and with PAH4 (the plain sum of the four) above 10.0 ng/g, the EU limits for oils the report cites |

**Reported, not graded:** the detected shares against 47 / 39 / 82 / 61%; origins by the Function
column against Table 1 (the census already shows formula 0/32/2 vs 0/31/3 and olive oil 1/135/12
vs 1/133/14); benzo[a]pyrene alone per type; the sampling-date column (distinct dates, most samples
on one date); and a twin scan for samples with identical values for all 16 PAHs, or for the four
TEQ PAHs when two or more are detected. The scan found two copied-looking pairs in the 2018-19 PAH
file.

**Arithmetic from the printed figures alone:** given the formula and nut rows, the total row's
0.21 allows an olive-oil average from 0.2265 to 0.2464, so it fits both 0.23 and 0.24. The test
`test_printed_rows_add_up` pins this.
