# pah-2018 0.1.0 addendum: a whole-file scan for identical samples finds a second pair (a roasted pepper and a cookie)

The result note [pah-2018-0.1.0-result.md](pah-2018-0.1.0-result.md) (tag `v0.4.88`) reported
one exploratory lead: two oils with different products and origins carry identical values for
all 16 PAHs. It promised a scan of the whole file for other such samples. This is that scan.

## How it ran

The sealed job `pah-2018-result-v1` ran on 2026-10-31 at 08:54 UTC (python:3.12, 1 GB). It fetched
the published `data/pah_2018_samples.csv`, `data/pah_2018_summary.json`, the result note and
`test_pah_2018_result.py` from GitHub, and re-ran the pinned test on them. **All 12 tests passed**:
the published result re-runs from GitHub. Then `twin_scan.py` grouped all 287 samples by their 16
PAH values and printed every group of two or more samples whose values are all equal, counting
only samples with at least one PAH above 0. It ran the same check on the four TEQ compounds
alone.

## What it found: exactly two identical pairs

| Pair | Sample | Product | Origin (Function) | Region | PAHs above 0 | TEQ (ppb) |
|---|---|---|---|---|---|---|
| 1 | `C2018PAHS00282` | Oil - Soybean | United States (Import) | Quebec | 4 | 0.059183 |
| 1 | `C2018PAHS00291` | Oil - Sunflower | Turkey (Import) | Quebec | 4 | 0.059183 |
| 2 | `C2018PAHS00017` | Pepper (roasted) | Greece (Import) | Ontario | **14** | 0.723741 |
| 2 | `C2018PAHS00095` | Bakery Product - Cookie | Unknown (Unknown) | Ontario | **14** | 0.723741 |

Pair 1 is the one already reported. **Pair 2 is new.** A roasted pepper and a cookie share 14
non-zero values to four decimal places (ng/g): acenaphthene 0.2039, acenaphthylene 7.5364,
anthracene 2.4815, benzo[a]anthracene 0.6156, benzo[a]pyrene 0.6023, benzo[b]fluoranthene
0.5666, benzo[g,h,i]perylene 1.369, benzo[k]fluoranthene 0.5549, chrysene 0.3221, fluoranthene
6.4098, fluorene 2.3306, naphthalene 2.8941, phenanthrene 7.3072 and pyrene 7.774. The other two
are 0 in both. Of the 287 samples, 275 have at least one PAH above 0. Restricted to the four TEQ
compounds, the 133 samples with a TEQ above 0 give the same two pairs and no others.

Fourteen values agreeing to four decimals between two unrelated foods is not a plausible
coincidence. It points to a copied row. The file cannot say which sample's results are the real
ones, or whether either is. Both pairs sit in one region each (Quebec; Ontario), which fits a
copy made where results were entered, but that is a guess.

## Does it change the graded result?

No. Table 2 reproduced in full from the file as published, so the report's figures were computed
from the same rows, copies included. If one sample in each pair were corrected, the group averages
in Table 2 would move. With n this large the change would be small, but it cannot be computed
without the true values. The graded items and the pinned test stand as published.

## Limits

This was a planned exploratory scan, not a pre-registered prediction. Exact equality is a strict
test: rows copied and then partly edited would not be found. The same scan will run on every
per-sample file this series grades (the bisphenol grader already includes it, for samples with
two or more bisphenols above 0).
