# Pre-registration: a natural-chromium ceiling-inflation stress test for the Pb:Cr chromate screen (cr-ceiling-stress 0.1.0)

**Author:** MV2, Munim, Inc. (mv2@munimtech.com). Work made with AI agents.
**License:** text CC BY 4.0; any code Apache-2.0.
**Status:** pre-registered. Written and committed *before* the analysis is run. The result note and data will be a separate, later commit, graded against the predictions below.

## Why this exists

The open `cr_baseline` analysis in this repo scores the 34 NYC lab spice pairs that look
like lead chromate (Pb:Cr molar near 1) against spice-specific, method-stratified natural
chromium ceilings taken from the primary literature. Its headline is that **32 of the 34
pairs are "robust"** — their chromium is higher than any published natural level for that
spice could supply — while only the two coriander pairs stay "unresolved".

Every "robust" verdict rests on one modelling choice: the set of published natural-chromium
ceilings used per spice. A fair critic asks: *how fragile is "32 of 34" if those ceilings
are too low?* Real natural chromium can vary with cultivar, soil, and (for some methods)
analytical bias, and the literature is thin for several spices. This analysis answers that
critique quantitatively, before looking at the answer, so it cannot be tuned in hindsight.

## Method (fixed in advance)

Inputs: the committed `data/cr_baseline.csv` on `main` (one row per chromate-like pair),
using only its existing columns `baseline_verdict`, `edge_ppm`, and `highest_ceiling_ppm`.
No new chemistry; a pure, deterministic transform of already-published bytes.

The tool's own rule (`cr_baseline.py` `judge`) calls a pair **robust** when *no* ceiling in
its matrix reaches the pair's `edge_ppm` (the largest natural chromium removable before the
Pb:Cr ratio leaves the chromate band). Scaling every ceiling by a factor *s* keeps a robust
pair robust exactly while `s * highest_ceiling_ppm < edge_ppm`, i.e. while

    s < k,  where  k = edge_ppm / highest_ceiling_ppm.

So **k is the exact multiplicative headroom**: the factor by which *all* published natural-
chromium ceilings would have to be simultaneously inflated before that pair stops being
robust. For each robust pair we compute k; the number of pairs surviving a uniform inflation
*s* is the count of robust pairs with `k > s`. We report survival at
s ∈ {1.25, 1.5, 2, 3, 5, 10} and the single most fragile robust pair (smallest k).

## Predictions (falsifiable; graded next run)

- **H1 (sanity).** All pairs with `baseline_verdict == "robust"` have k > 1.0; exactly 32
  pairs are robust; the two unresolved pairs (both coriander) are not in the robust set.
- **H2.** The most fragile robust pair is the Algerian **turmeric** pair
  (edge_ppm 3.59, highest_ceiling_ppm 2.88), with k = 1.247 ± 0.003. *(This tests the prior
  note that its margin, 0.71 ppm, is the tightest; margin is not the same as ratio, so H2
  may fail even if H1 holds — that would itself be worth reporting.)*
- **H3 (main hypothesis).** Doubling every published ceiling (s = 2) leaves **at least 24 of
  the 32** robust pairs still robust — i.e. the "32 of 34" headline is not fragile to a 2×
  error in assumed natural chromium.
- **H4.** Survivor counts are monotonically non-increasing across s = 1.25, 1.5, 2, 3, 5, 10,
  and at s = 10 at most 8 pairs remain robust.

A failure of H3 or H4 is a real, informative result and will be reported as a failure, not
hidden. H1 is a near-definitional check that the committed data matches the tool's logic.

## Outputs (next commit)

- `data/cr_ceiling_stress.csv` — one row per robust pair: ids, product, country, edge_ppm,
