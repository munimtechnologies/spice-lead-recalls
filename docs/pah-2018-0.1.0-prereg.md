The grading code is `pah_2018.py`, and its offline tests are `test_pah_2018.py`. A sealed compute

out the published code, then reads the file.

Nothing here is a finding about any product, brand or health risk. The report notes that Canada
had no maximum levels for PAHs in these foods in 2018-19 and cites the EU limit for oils for
comparison; this check is about whether the open file and the printed figures agree.

## Why this is new

Searches on 2026-10-30 found the CFIA report page and PDF, the open dataset records for 2018-19
and 2019-20, and a 2026 exposure study that cites the report. They found no analysis of the
per-sample open file and no check of it against the printed figures.

## What the printed figures say about each other (no data)

- **The sunflower list is an exact copy of the soybean list:** the same seven values in the same
  order.
- **Figure 1 lists 56 detected oils; Table 2 says 55.** If the sunflower list is a copy, the
  other seven lists hold 49, which leaves **6** sunflower detections.
- **Table 2's oil average does not fit Figure 1 as printed.** The 56 listed values sum to
  15.607718 and average 0.279 (which prints as 0.28, not 0.27). For Table 2's 55 values to average
  0.27 (0.265-0.275), their sum must be 14.575-15.125. The seven non-sunflower lists already sum
  to 14.879979, so six real sunflower values would have to sum to at most 0.245.
- Peanut's nine values average 0.9448 (prints 0.94); canola's two average 0.018 (0.02), maximum
  0.0338 (0.03). Table 2's detected counts add to 133, and its weighted average is 0.408 (0.41).
  `printed_internal()` recomputes all of this.

## Rules (fixed now)

- **Columns** by header: `Sample No.`, `Product` (English), `Component` (English),
  `MaxOfAMOUNT`, `Report Unit`, `PLAN_CODE`; also `Function`, `Origin`, `Region`.
- **Value rule:** a number above 0 is detected; 0, a `<` with a number >= 0 or a not-detected
  token is not detected (counts as 0); anything else fails the gate. Each component's value is the
  largest of its rows.
- **TEQ** per sample = BaP + 0.1 BaA + 0.1 BbF + 0.01 Chr (ng/g = ppb). A sample is **detected**
  if its TEQ is above 0. Averages are over detected samples only.
- **Groups and oil types** as in the census section above.
- **"Matches"** means the value rounds to the printed figure at its printed precision (for example
  0.0337585-0.0337595 for "0.033759", 0.935-0.945 for "0.94").
- **Figure 1 matching:** a type's list matches **in full** if the file has exactly as many
  detected samples of that type as the list has values and each printed value pairs with a
  different file value that matches it.

## Gate (G)

File size 850,814 bytes (the portal's record; the MD5 is compared and reported, not gated); the
five key columns; 4,592 rows; 287 samples with IDs of the form C + 4 digits + letters + 4-6 digits; each sample with exactly
one row for each of the 16 PAHs; unit ng/g and plan `2018_TS024` on every row; only the 16 known
product labels; every value passing the value rule. If G fails, nothing else is graded.

## Predictions (P1-P6)

- **P1.** Figure 1 reproduces for the seven oil types other than sunflower: at least 6 of the 7
  lists match in full.
- **P2.** Sunflower: the file has exactly **6** detected sunflower oils, at most 1 of the 7
  printed sunflower values is matched by them, and 55 oils are detected in all.
- **P3.** Table 2, baked goods and roasted vegetable products: at least 7 of the 8 cells
  (detected, minimum, maximum, average) match.
- **P4.** Table 2, oils: detected 55, minimum 0.002, maximum 2.41 and average 0.27 all match.
- **P5.** Table 2, grand total: 133 detected (46%), minimum 0.001, maximum 9.17 and average 0.41
  all match.
- **P6.** The text: peanut has the highest average (0.94) and maximum (2.41) of the eight oil
  types; canola has 2 detected of 11 and the lowest rate, average (0.02) and maximum (0.03); the
  survey maximum 9.17 is a `Pepper (roasted)` sample and every other roasted vegetable is below
  2.7; exactly one baked good is at 0.8 or more, and it is 1.68.

Competing readings, stated now: for P2, **the figure is right and Table 2 is wrong** (the file has
7 sunflower detections that equal the soybean list, or 56 detected oils), or the file itself
repeats the soybean values for sunflower. For P1-P5, CFIA's TEQ could use other factors or count
"detected" by any of the 16 PAHs; the summary reports benzo[a]pyrene alone and the any-PAH counts
so that can be seen.
