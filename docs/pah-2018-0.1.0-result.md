# pah-2018 0.1.0: CFIA's open 2018-19 PAH file against every figure CFIA printed for it — result

RESULT-MARKER: pah-2018-0.1.0-result

By MV2 of Munim, Inc. Prepared with AI agents working in his name. Text CC BY 4.0; code Apache-2.0.

This grades the pre-registration [pah-2018-0.1.0-prereg.md](pah-2018-0.1.0-prereg.md), which was
public first, at tag `v0.4.85`. The sealed job `pah-2018-v1` ran on 2026-10-31 at 00:44 UTC
(python:3.12, 1 GB, no host paths). It waited for the registration's marker to be public,
checked that its bundled `pah_2018.py` and `test_pah_2018.py` were byte-identical to the
published copies, ran the offline tests and only then read the file (850,814 bytes; its MD5
matches the portal record; SHA-256 `9b93f733…1a1650e`). **The gate passed, and 6 of 7 graded
items held: G, P1, P3, P4, P5 and P6.**

This is a reproducibility check of open government data, not a compliance finding and not about
any brand. The report notes that Canada had no maximum levels for PAHs in these foods in 2018-19.
All results are total PAH in ppb TEQ (benzo[a]pyrene + 0.1 x benzo[a]anthracene + 0.1 x
benzo[b]fluoranthene + 0.01 x chrysene), as the report defines it. It is not dietary or medical
advice.

## Exploratory, after grading (not pre-registered)

**Two different samples carry identical results.** `C2018PAHS00282` (`Oil - Soybean`, imported
from the United States, Quebec region) and `C2018PAHS00291` (`Oil - Sunflower`, imported from
Turkey, Quebec region) have the same value for all 16 PAHs: benzo[b]fluoranthene 0.5508,
chrysene 0.4103, fluoranthene 0.4128 and pyrene 0.6286 ng/g, and 0 for the other twelve. Both
have TEQ 0.059183. This is the one soybean value that matches the printed (copied) list.

Two samples with different products and origins agreeing on four values to four digits looks
more like a copied row than a coincidence, but the file cannot say which sample's results are
real, or whether both are. We found this pair by reading the soybean and sunflower rows. The
post-publish job scans the whole file for other samples whose 16 values are all identical and
prints what it finds; the next note reports it.

## Limits

- "Detected" is the file's own coding (a value above 0). The file gives no reporting limit per
  sample.
- P2 failed because we guessed the wrong panel. The registration's competing readings named
  "the figure is right and Table 2 is wrong" and "the file repeats the soybean values for
  sunflower"; neither holds either. The reading the file supports, that the soybean panel is the
  copy, was not registered.
- The identical pair in the exploratory section was found after grading by reading two labels'
  rows. It is a lead, not a result.

Prior art: searches on 2026-10-30 found the CFIA report page and PDF, the open dataset records and
a 2026 exposure study that cites the report. They found no analysis of the per-sample file and no
check of it against the printed figures.

## Reproduce it

- `data/pah_2018_samples.csv` is the sealed job's output, one row per sample: ID, product, group,
  oil type, function, origin, region, TEQ, number of PAHs detected and all 16 PAH values in ppb.
- `data/pah_2018_summary.json` is the sealed grader record: the gate, every prediction with
  observed values, the printed-figure arithmetic, census and provenance.
- `test_pah_2018_result.py` is a pinned test. It does not import the grader. With its own code
  and its own copy of the printed figures, it recomputes every TEQ from the 16 PAH columns and
  checks against the sealed record:
  - the counts, labels, groups and Table 1 origins;
  - every Table 2 cell;
  - all eight Figure 1 lists, the soybean copy and the corrected 0.27 average;
  - the text's peanut, canola, roasted-pepper and baked-good figures;
  - the identical soybean/sunflower pair.

A sealed follow-up job (`pah-2018-result-v1`) fetches these published files from GitHub and
re-runs the pinned test on them. The grading code `pah_2018.py` and the pre-registration are at
tag `v0.4.85`.
